# ===== RASPBERRY PI INSTALLATION NOTES =====
# 
# 1. Install system dependencies first:
#    sudo apt update
#    sudo apt install -y python3-pip python3-venv python3-dev
#    sudo apt install -y python3-pyside6.qt6 qt6-base-dev
#    sudo apt install -y libopencv-dev python3-opencv
#    sudo apt install -y v4l-utils  # For camera support
#    sudo apt install -y libgl1-mesa-glx libglib2.0-0  # OpenGL support
#
# 2. Create virtual environment:
#    python3 -m venv venv
#    source venv/bin/activate
#
# 3. Upgrade pip and install wheel:
#    pip install --upgrade pip setuptools wheel
#
# 4. Install requirements (this may take 30-60 minutes on RPI):
#    pip install -r requirements.txt
#
# 5. If opencv-python fails to install, try:
#    pip install opencv-python-headless  # Lighter version without GUI features
#
# 6. If onnxruntime installation fails, try:
#    pip install onnxruntime --no-cache-dir
#
# 7. For better performance on RPI 4/5, consider:
#    - Using 64-bit OS (Raspberry Pi OS 64-bit)
#    - Allocating more GPU memory if using GPU acceleration
#    - Using lighter models or reducing input resolution
#
# ===== PERFORMANCE TIPS FOR RPI =====
# - Use lower video resolution (640x480 or 320x240) for better FPS
# - Reduce confidence thresholds to speed up processing
# - Disable unused detection models
# - Consider using opencv-python-headless if GUI features not needed
# - Monitor CPU temperature: watch -n 1 vcgencmd measure_temp
